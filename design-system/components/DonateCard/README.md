# DonateCard

Numbered method cards in a hairline grid: mono number, uppercase heading, body copy and optionally an address block or an em-dash list.

**The consumer provides** the method name (link it with a `violet` `↗` if it leaves the site), one or two sentences, and either a `pre` (postal address, wire details; `bg-inset` with the `violet` bar) or a `.donate-card__sub` list (em-dash markers in `violet`).

Numbers are mono 12px `violet`; padding is 32px. Use the same pattern for any "ways to…" section.
