# Callout

A recessed note: `bg-inset` fill, a 3px `violet` left bar (`stroke-accent`), `text-2` copy at line-height 1.6.

**The consumer provides** one or two short paragraphs, or a `pre` (set in mono, wrapping) for an address or code block. The same treatment styles Markdown `blockquote` and `pre` inside `.prose`, `.doc` and `.legal-doc`, and the board/legal notices.

**Don't** stack callouts, add an icon, or use coral for the bar; coral is reserved for actions.
