# DefinitionRows

Two-column ruled rows that a Markdown list of **Label:** text items becomes inside `.doc`.

**The consumer provides** a Markdown bullet list where every item starts with a bold label. The label sits in a 220px left gutter (700 weight, stretch 108%, `text`); the description keeps normal inline flow in `text-2`, so inline links stay inline. Rows have `rule` top and bottom borders.

Below 1000px the label stacks above the description. Use it for facts, terms and FAQs; use plain prose for anything that needs more than two sentences.
