# RowList

A vertical list of full-width links, each on its own ruled row with a mono `↗` arrow at the right.

**The consumer provides** a `ul.row-list` of `li > a`. For non-link rows use `li > .row-list__row` (no arrow).

**Rules** rows are min-height `space-cta` with a 1px `rule` bottom border; text is `text`, the arrow `violet`; hovering a row turns both `coral`. Use it for indexes of documents and pages, not for inline navigation.
